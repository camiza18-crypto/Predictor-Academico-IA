🎯 Matriz de Confusión

Interpretación

¿Qué es la Matriz de Confusión?

Muestra la comparación entre valores predichos vs reales. Cada celda representa cuántos registros fueron clasificados en cada categoría.

Diagonal Principal

Los valores en la diagonal son predicciones CORRECTAS. Mientras más altos, mejor el modelo.

Fuera de la Diagonal

Son errores de clasificación. El modelo confunde una clase con otra.

📝 Variables de Entrada

  • Unidades Aprobadas (2do sem): Número de cursos completados
  • Calificación (2do sem): Promedio de notas
  • Pago de Arancel: Situación financiera (0=Al día, 1=Atrasado)
  • Beca: Beneficiario de ayuda (0=No, 1=Sí)
  • Calificación de Admisión: Puntaje de ingreso inicial

🎯 Clases de Salida

  • Dropout (🚪): Estudiante que abandonó
  • Enrolled (📚): Estudiante actualmente matriculado
  • Graduate (🎓): Estudiante que se graduó

⚙️ Técnicas Utilizadas

  • StandardScaler: Normalización de datos (media=0, desv.est=1)
  • Train-Test Split: 80% entrenamiento, 20% prueba
  • ReLU: Función de activación no lineal
  • Dropout: Regularización para evitar overfitting
  • Softmax: Probabilidades para 3 clases
  • Adam: Optimizador adaptativo
